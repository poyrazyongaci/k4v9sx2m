# Bench variant table. Baked into the image as /bench/variants.txt.
#
# build NAME TREE [VAR=VAL ..] [cfg=NAME ..]
#   builds variants/TREE with the real Dockerfile's flags into /bench/bin/NAME.
#   VAR=VAL is set for cargo (layout knobs SS_EVENTS_PAD, SS_EXIT_PAD,
#   SS_DIE_PAD); cfg=NAME adds `--cfg NAME` to RUSTFLAGS.
# run NAME BIN [VAR=VAL ..] [kind=proto|kind=probe]
#   one timed variant: BIN is a build NAME, an absolute path, or @self (the
#   driver as a fake engine, with BENCH_FAKE=crash|fail|wrong; tests only).
#   ENGINE_TIMING=1, DATA_DIR and OUTPUT_DIR are always set by the driver.
#   kind=proto: a prototype; its answer is compared and reported, never bad.
#   kind=probe: writes no output, prints no self-check; wall and parse only.
#
# The first run line is the base: its binary writes the real dev answer, its
# answer is the reference, and paired differences are against it. A run line
# identical to the first (same BIN and env) measures the noise floor.

build default    default
build cand       cand
build a          a
build b          b
build c          c

# Priority order: if time is short the soft budget drops whole rounds, never
# variants; the order here is the warm-up order and round 1's order.
run default     default
run asm         cand ENGINE_ASM=1
run a           a ENGINE_ASM=1
run b           b ENGINE_ASM=1
run c           c ENGINE_ASM=1
